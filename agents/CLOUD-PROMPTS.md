# Ready-to-paste prompts for cloud sessions (claude.ai/code)

Open claude.ai/code, pick the repository `Synaptikk/SmartLights`, start a new session, and paste ONE prompt below. Run several sessions in parallel; each works on its own branch and opens a pull request. Cloud sessions have no Apple toolchain either: the macOS GitHub Actions workflow is the compiler, and every prompt tells the agent to iterate until CI is green.

Status as of 2026-10-27: merged or in PR: LightCore, NetKit, Simulators, Onboarding, Diagnostics, App shell, HomeKit, Hue, WiZ, AiDot, LIFX (PR 1), Nanoleaf (PR 2), Siri intents (PR 3), Yeelight (PR 5), Govee and app provider wiring (in progress locally). Do not start those.

Common preamble (already included in each prompt): read `CLAUDE.md`, `PLAN.md`, `agents/TASKS.md`, the brand's rows in `docs/BRAND-RUNDOWN.md` and `docs/ONBOARDING-WALKTHROUGHS.md`, and study `Packages/Providers/HueKit`, `WiZKit`, `LIFXKit` as house style (codec/transport split, `LINUX_OK`, Swift Testing, in-package fake device for tests).
