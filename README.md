# SmartLights

One iPhone app for every smart light brand in the house. Planning package, 2026-10-26.

| File | What it is |
|---|---|
| `PLAN.md` | Master plan: research summary, decisions, architecture, phases, prerequisites, risks |
| `agents/TASKS.md` | Work breakdown with acceptance criteria for the implementing agents |
| `CLAUDE.md` | Standing instructions for agents working in this repo |
| `docs/BRAND-RUNDOWN.md` | Every brand: hub, protocol, cloud, Matter, HomeKit, difficulty, tier/phase |
| `docs/ONBOARDING-WALKTHROUGHS.md` | Per-brand end-user walkthroughs that become the in-app "Add brand" wizard |
| `research/` | Seven sourced research reports (Hue, WiZ, AiDot, other brands, existing projects, iOS platform + Hue bridge modding, onboarding) |

Quick start for an agent: read `CLAUDE.md`, then `PLAN.md`, then pick a task in `agents/TASKS.md` phase 0.
